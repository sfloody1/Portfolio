# T1R Binding Mechanism

This project investigates how sweet and umami ligands interact with the T1R receptor system by modeling binding behavior, fitting concentration-response curves, and comparing receptor activity across different ligand conditions.

## Objective

To quantify how ligand concentration affects receptor occupancy and to compare the apparent binding behavior of sweeteners and modulators within a T1R-related signaling framework.

## Skills Demonstrated

- Python programming and scientific computing
- Nonlinear curve fitting and parameter estimation
- Biophysical modeling of receptor-ligand interactions
- Statistical analysis of binding and response data
- Data visualization with Matplotlib
- Interpretation of concentration-response relationships
- Computational analysis of sensory receptor mechanisms

## Workflow

1. Import concentration-response data for T1R-related ligand conditions
2. Fit binding curves to estimate apparent saturation and affinity parameters
3. Compare control and modulated conditions, including IMP-dependent effects
4. Plot receptor occupancy over a logarithmic concentration range
5. Evaluate differences in relative sweetness and activation across ligands
6. Interpret how ligand structure and concentration shape receptor engagement
7. Summarize the findings in a notebook-based analysis

## Tools Used

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- Jupyter Notebook
- Receptor-ligand binding analysis

## Outputs

- Fitted binding curves and estimated Kd/Bmax values for ligand conditions
- Comparison of receptor response across sweeteners and modulating compounds
- Visualizations of binding and relative sweetness trends
- Notebook-based summary of T1R-related mechanism interpretation
